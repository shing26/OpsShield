# 统一工作台：一个壳、两个面，抽屉按身份分级

状态：accepted（2026-10-19）

上下文：ADR-0009 立了面板 `/`（只读可观测面，消费 `/admin/state` + `/admin/audit/recent`），
ADR-0020 立了排障台 `/troubleshoot.html`（单次请求的协议面证据，任意有效 JWT）。两者门禁不同、
视角不同，于是长成了两个割裂的页面：值班的人一边开着面板看档位与风暴，一边开着排障台贴报错，
**中间没有任何连接**——面板上的数字跳动与排障台里刚发生的那次请求是两回事。四个实测事实把
"合并"这件事的成本钉在明处：

1. `scripts/check_panel_contract.sh` 把 `HTML=src/main/resources/static/index.html` **硬编码**在
   脚本里，四层契约门闩全绑这个路径；`scripts/demo.sh` 另有一条 `[ -f .../index.html ]` 断言。
2. `scripts/liveness.py` 用 `GET /` 的 HTML 里必须含 `OpsShield` 锚点做**身份判据**（防端口被别的
   项目占用，实测 8080 上的 nexus-web 同样回 `{"status":"UP"}`），有 16 例回归锁。
3. `docs/DEMO.md` 的"底幕"就是 `/` 上的面板（粘 L3 JWT 接入），演示脚本里有多处"指着面板说"的动作。
4. 两个页面体量相当（505 行 / 550 行），共享一个壳之后总量反而下降。

决策：**`/` 变成统一工作台**——一份 HTML、两个视图，默认视图是排障台。

1. **一个壳**：导航、账号胶囊、健康抽屉、高级入口只存在一份。面板视图是同一页面里的第二个视图，
   **不是第二个文件**。`/troubleshoot.html` 保留为薄壳或 302，避免旧链接与文档失效。
2. **抽屉按身份分级**：健康抽屉的数据源只有 `/api/v1/admin/state` 与 `/admin/audit/recent`，两者
   在 `AdminController` 里统一要求 `role=platform ∧ auth_level>=3`。platform 身份出数据，其他身份出
   **锁定态**（"需要平台凭证"）。**门禁一字不动**，不为这个页面新开非 admin 的状态端点。
3. **三层分工**：右上角 = 会话级（我是谁 / 系统健不健康 / 有没有高级能力）；左栏 = 任务级
   （排障输入、预设、发起）；主区 = 证据（命令清单、正文、引用）。
4. **凭据入口唯一**：页内用户名 + 口令（ADR-0020 决策②），token 存 `sessionStorage`——刷新不掉线、
   关标签页即失效。页面侧的"粘贴 token"入口退役；`scripts/console_token.sh` 保留，但它服务的是
   curl / 探针 / 自动化，不是页面。合并后页面启动时**主动清掉旧的 `opspilot.jwt` 键**。
5. **对照模式降为高级入口**：挂在右上角的「高级 · 权限隔离演练」下；**预设不再自动切换模式**。

理由：

① **"点一次查询、右上角数字当场跳一下"只有在同一份页面状态里才成立**——跨页面做不到，这是合并
唯一不可替代的收益。
② **共享外壳、两个 HTML 的路线会引入"两个壳手工同步"的漂移面**。这个仓库对漂移的一贯态度是建
门闩，而这里最省事的门闩就是"只存在一份壳"。
③ **抽屉按身份分级而不是新开端点**：档位、命中率、配额水位都是**跨租户聚合**，给低密级身份开这个
口子的代价远大于这次改造要买的东西；而锁定态本身是诚实的，它明确告诉低密级用户"这一块是平台面"。
④ **`sessionStorage` 与"一次值班"的语义对齐**：值守时刷新一次不该把人踢出去，共享机器上关掉标签页
凭据就该消失。**必须诚实标注**：它不是安全升级，同源脚本照样读得到，只是**生命周期收窄**——不得在
文档里写成"更安全"。
⑤ **粘贴 token 路径退役**：`console_token.sh` 内部就是 `localapi.login('sre-full')`，**它自己也要用
`.env` 里的口令**，所以那条路径没有减少任何凭据暴露；而保留它就要重新回答"这枚 token 还有效吗"
（探针会真的走检索并落一行审计，正是 ADR-0020 决策②要消解的问题），还要为它单独处理 403
（`sre-acme` 是 level 3 但不是 platform，会撞面板门禁）。两个凭据入口 = 两套 401/429/403 文案与
两套生命周期，成本落在最不该出错的地方。

备选与否决：

| 被否项 | 理由 |
| --- | --- |
| 共享 `shell.css` / `shell.js`，两个 HTML | 引入两个壳手工同步的漂移面；且"看起来是一个工作台"并不带来第 ① 条的收益。 |
| 不合并，两页互链 | 无法满足"排障时同屏看见运行态"这个诉求，等于不做。 |
| 抽屉对所有身份开放（新开非 admin 状态端点） | 需要重新裁定"哪些跨租户聚合量可以给低密级看"，开的口子远大于收益。 |
| 抽屉只对 platform 渲染（非 platform 连占位都没有） | 同一页面在不同身份下结构不同，解释成本高；ADR-0020 已以同样理由否掉过"可选加成"。 |
| token 存 `localStorage`（沿用面板今天的行为） | 在共用的值守机上留一枚 24h bearer token。 |
| token 只存内存（刷新即掉线） | 实际使用里会很快被人用"干脆存起来"绕过去，不如一开始就选对。 |
| 页内登录 + 粘贴 token 并存 | 见理由 ⑤。 |

后果：

- **连带改动**：`check_panel_contract.sh` 的 HTML 路径、`demo.sh` 的存在性断言、`DEMO.md` 的底幕
  段落、README 的架构图与端点表——一次改完，之后长期受益。
- **`liveness.py` 的锚点必须保留**：`/` 的 HTML 里必须继续含 `OpsShield`，否则外部存活探测会把
  "端口被别的项目占了"判成"OpsPilot 挂了"（16 例回归锁盯着）。
- **单文件阈值**：合并后 HTML 约 900 行。ADR-0009 把"单文件、零 CDN、缓存成本≈0"当资产，900 行
  仍在可维护范围内，但这是**阈值告警**：若该文件继续显著增长（覆盖清单、零依赖提示都进来之后），
  应重新评估拆出 `shell.js`，而不是让它变成第二个"没人敢改的 3000 行页面"。
- **对照模式**：ADR-0020 的五条决策不变，仅视觉层级从"并列模式"降为"高级入口"（见该 ADR 的注记）。

相关：ADR-0009（只读可观测面）、ADR-0020（排障台）、ADR-0008（每条共享路径都有权限维度）；
操作面见 OPS §9/§12。

## 注记（2026-10-19 落地实测）

五条决策一字未改地实现了。下面记的是**实现里才撞出来、正文没写到**的东西，以及阈值判定。

**体量（如实登记）**：`index.html` 落地后 **1363 行**（本 ADR 预测约 900，低估 50%），
`troubleshoot.html` 35 行（meta refresh + JS 带 hash 跳转，旧书签不失效）。
**已越过本 ADR 自己写的告警线**。但拆 `shell.js` 的触发条件不该是行数本身——本轮已把职责切干净
（`renderHeader` / `renderAcct` / `renderAdv` / `renderRail` / `renderCanvas` / `renderDrawer` /
`renderPanelGate`，每个只碰自己那块 DOM，面板侧的渲染函数原样搬过来未改），
**真正的触发条件是"下一次改动需要同时改三个以上这些函数"**——那时拆，不早拆。

**四个实现级决定（正文没有，但都是有意选的）**：

1. **`platform` 是三态，不是布尔**：`null` 未实测 / `true`（`/admin/state` 200）/ `false`（403）。
   布尔会让第一次请求返回之前就渲染出"当前身份的 `/admin/state` 返回 403"——
   **未实测就下结论**，与仓库的诚实性红线冲突。三态下这段时间显示"正在读取运行态…"。
2. **非平台身份停轮询**，不拿 403 反复打端点。代价必须写下来：浏览器控制台会留两条
   `Failed to load resource: the server responded with a status of 403`——那是**网络层日志，不是 JS 异常**。
   任何"控制台零错误"的验收口径要把它排除在外；唯一的替代是客户端解 JWT claims 预判，
   **否决**：那等于把门禁从服务端搬到客户端，正是决策 2 要避免的事。
3. **空态不挂用户名**：没有结果时若照常渲染报告卡，会得到一张顶着 `sre-full` 的"还没有结果"卡，
   读起来像"这个人已经问过了"。改为纯空态文案。
4. **`pendingAsk`**：未接入时先填输入或点预设 → 挂起意图并打开账号胶囊，接入成功后自动发起；
   左栏主按钮在未接入时的职责是「接入身份」（直接开胶囊），不是「发起排障查询」——
   否则会拿空口令去打一次注定 401 的请求（ADR-0020 第 2 条同一口径）。

**顺带修掉的一处"简陋"**：答案正文里的围栏代码块（模型实测会吐 ` ```sql `）旧渲染器把反引号
原样显示出来，是排障台"简陋感"最刺眼的一处。现在按原文渲染成 `<pre class="md-code">`，
**围栏内不套行内标记**——代码里的 `**` 与 `[参考N]` 都是字面量，套了就是二次篡改。

**门禁与端点复核**（一字未动）：`scripts/check_panel_contract.sh` 四层 + `scripts/demo.sh` 七检全绿；
`mvn -B test` 253/253；`doc_numbers.py --check` 23 数 37 引用；`provenance.py --check` 通过。
浏览器实测（1440×900 / 390×844）：单身份带契约、双身份差集、拒答、澄清四态正常，
窄屏无横向溢出，`/troubleshoot.html` 正确跳转到 `/`。

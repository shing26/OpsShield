# 0044. RCA 入口迟滞下 B0 未通过：告警入口路线作废，转自建检测

- 状态：Proposed（待 Lead 签收）
- 日期：2026-11-27
- 契约：`plans/rca-entry-robustness-accept.md`（FROZEN）
- 上位：`plans/rca-roadmap.md`（路线 B 的 B0）
- 证据：`offline/rca/reports/R4-report.md`

## 背景

v3 的定位增益有一个前提：检测起点已知。路线 B 想绕开检测，直接用 OpsPilot
既有告警的时间窗做入口。它成立的前提是“告警比真实起点晚 1–5 分钟时，增益
还在”。B0 就是这个前提的可证伪检验。

## 决策

**按冻结契约判 B0 未通过，路线 B 作废，转路线 A（自建检测）。**

## 证据

δ=120s 时 `dual-arm-rrf` Top-1（SS / OB dev 各 75）：

- RE1-SS：0.960 → 0.747（−21.3pp），delay −40.0pp、loss −46.7pp、mem −13.3pp。
- RE1-OB：0.893 → 0.840（−5.3pp），loss −13.3pp。

主门槛（≤5pp）与分故障门槛（≤10pp）在两套 dev 上均未通过。

δ=0 精确复现 v3 dev（各 600 行 0 处不一致），说明失败不是实现漂移。

## 否决项

- **把 δ=300s 的回升当成“迟滞无害”**：曲线非单调，且该点是基线窗口缩短造成的，
  不能读成可用性结论。
- **用“基线被污染”解释掉 FAIL**：这是本实验的固有混淆，已在报告 §4 写明，
  但它不改变判定；要测固定尾随基线必须另立契约。
- **在本次数据上重挑基线长度或 δ 网格**：看到结果后再定窗口参数即为调参。
- **声称路线 B 仍有产品价值**：按契约，它已作废。

## 后果

- 正面：用一次低成本实验（两人日量级）否掉了一条会反复吸引投入的产品捷径。
- 正面：确认 `dual-arm-rrf` 的秩融合对“尺度整体缩小”比 3σ 稳（SS δ=300s：
  0.920 vs 0.040），这是方法本身的可用性质，与路线判定无关。
- 负面：路线 B 作废意味着阶段 4（自动发现）无法绕开；端到端仍然不可用。
- 后续：转路线 A。A1 沿用 v2 冻结判据（SS/OB dev 覆盖 ≥80% 且误报 ≤5%），
  先定义新特征（跨服务一致性、持续时间、调用链上下文），在 dev 上见分晓，
  不得在 TT 上调阈值。

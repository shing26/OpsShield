接入管理

Web 之外，第三方系统可通过 OpenAI 兼容接口调用同一编排链路

凭证API Key 即 OpsPilot JWT
这是凭证，等同于你的身份与密级。不要提交到代码仓库或暴露在前端日志中。
可用接入面
· Web SSE：POST /api/v1/copilot/chat/stream
· OpenAI 兼容：POST /v1/chat/completions（需 stream=true）
· 模型列表：GET /v1/models
快速接入curl 示例
# 用 JWT 作为 Bearer Key curl https://opspilot.internal/v1/chat/completions \ -H "Authorization: Bearer $OPSPILOT_KEY" \ -H "Content-Type: application/json" \ -d '{ "model":"opspilot", "stream":true, "messages":[{"role":"user", "content":"支付网关502怎么排查"}] }'
OpenAI 兼容面把 refs / actions 以 Markdown 注入正文末尾；Web SSE 面则给出结构化 meta / done 帧。

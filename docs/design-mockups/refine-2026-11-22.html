OpsShield · 界面精修阅览稿 · 2026-11-22

夜班控制台，不是 GitHub 深色皮

保留现有功能、信息与操作顺序，只重做气质与层级：把蓝色开发者面板换成夜班仪表台，把“每块都是同款卡片”换成“结论是读数，其余是记录”。

产品
给值班 SRE 的事件响应工作台：贴一条报错，得到有引用的结论、只读命令和可结单的事故记录。
性格
quiet · exact · alert
安静、精确、随时可接手。
世界
凌晨三点的控制室：石墨色仪表盘、蚀刻细线、方形信号灯、等宽日志。
时刻
诊断读数（结论 + 真实耗时刻度）；左栏事故时间脊。
签名
方形信号灯 + 带刻度的分区细线；只出现在状态、时间与读数上。

当前页面的主要问题

  • 气质是 GitHub 深色模板：蓝紫双强调、五枚胶囊控件、纯灰蓝面板，和“夜班排障”没有关系。
  • 层级靠卡片堆：结论、分析、命令、来源同宽同色同圆角，最重要的结论没有压过参考列表。
  • 空态是卡片套卡片：大边框里再放输入框和三张步骤卡，主操作被说明文字压到中部。
  • 字号失控：9–19px 之间出现十余档，9/9.5px 低于可读下限；650/700 字重混用。
  • 移动端真实断裂：左栏占 46vh 把事故推到首屏外；顶栏文字重叠；标题折成“连续超 / 时”；元数据变成六个整行胶囊。
  • 空卡占位：“只读命令 0 条”仍渲染整张卡和标题，读者要读三行才知道没有内容。

这版怎么改

  • 色彩：石墨偏绿的中性阶梯；象牙白只做主动作与选中；蓝紫退场。绿/黄/红只表示状态。
  • 层级：结论变成“读数面板”，带真实 10ms / 69ms 刻度；分析是正文，命令与来源是记录。
  • 空间：4px 网格；左栏 264、事实栏 288、正文 68ch；同组小间距、异组大间距。
  • 字：11/12/14/16/20 五档，400/500/600 三档；数字全部等宽、右对齐。
  • 移动：左栏收成“事故 1 · 进行中”切换条；标题 18px；元数据两列定义表；结单固定底部。
  • 空态：去掉卡片套卡片；一条输入、一个主动作、一条三步刻度线。

待你确认：方向（夜班仪表台 / 象牙白主动作 / 方形信号灯）与三屏版式是否接受。确认后我再改生产 index.html；若只想小步走，也可以只落“色彩 + 字号 + 空态 + 移动端”四项，保留现有单列卡片结构。
